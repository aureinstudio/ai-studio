## 측정 방법

1. `/studio`에서 5개 시나리오 각각 10회 실행
2. `/admin`의 "최근 작업" 섹션에서 시간·비용 데이터 수집
3. SQL로 집계:
   ```sql
   SELECT
     topic,
     AVG(duration_seconds) AS avg_time,
     AVG(cost_usd) AS avg_cost,
     COUNT(*) AS runs
   FROM studio_jobs
   WHERE status = 'completed'
     AND created_at > NOW() - INTERVAL '7 days'
   GROUP BY topic;
   ```
4. 결과를 본 문서에 갱신
