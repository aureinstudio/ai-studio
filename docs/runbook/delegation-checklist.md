# 본부장 위임 체크리스트

> 본부장이 직접 해야 할 일 vs 운영팀/강사/SME에 위임 가능한 일

## ❌ 본부장만 (위임 불가)

### 의사결정
- Gate G3 / 정식 출시 결정
- 차년도 예산·전략
- 인사·채용
- 가격 정책·요금제 변경

### 보안·법무
- 데이터 유출 사고 1차 대응 (L4)
- 법적 분쟁·환불 $500+
- service_role 키 rotation

### 학생 안전
- mental_health 신호 (severity=high) 학생 직접 연락
- 학생 사망·중상 대응

### 비용
- 월 예산 +30% 초과 결재
- HeyGen/Anthropic 플랜 업그레이드 결정

---

## ✅ 위임 가능

### 운영팀 (`operations`)
- 일일 모니터링 ([daily-ops.md](daily-ops.md))
- CS 문의 응대 (SLA 24h)
- 베타 신청 검토·승인 (자격 충족 시)
- 위험 학생 격려 메시지 (low~medium severity)
- 비용 임계 80% 알림 1차 대응
- 인시던트 L2 1차 대응 + 본부장 보고

### 강사 (`instructor`)
- 담당 과정 학생 모니터링
- 위험 학생 1:1 연락 (운영팀 위임 시)
- 콘텐츠 오류 신고 검토
- 주간 강사 보고 작성 ([/instructor/weekly-report](/instructor/weekly-report))
- 학생 질문 직접 답변 (Tutor 차단된 케이스)

### SME (`sme`)
- 콘텐츠 평가 (주 2회 자동 의뢰)
- 콘텐츠 오류 신고 사실 검증
- 콘텐츠 보완 큐 우선순위 결정
- 시험 출제 경향 업데이트

### 자동화
- 매일 03:00 — 위험 감지 + 격려 메일 + KPI 집계
- 매시간 — 학습 알림 발송
- 매주 월·목 — SME 검토 요청
- 매주 금 09:00 — NPS 응답 안내
