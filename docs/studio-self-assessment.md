- [ ] **1. 13 에이전트 풀 시스템 작동 확인**
      `/studio` → 주제 입력 → 파이프라인에 13개 에이전트 모두 표시되는지

- [ ] **2. 5개 시나리오 모두 성공**
      `docs/studio-e2e-scenarios.md`의 5개 시나리오를 각각 실행해 모두 `status=completed`

- [ ] **3. 평균 비용 $0.50 이하**
      `/admin` 또는 `/dashboard` → "평균 비용/건" $0.50 이하

- [ ] **4. 평균 시간 4분 이하**
      `/admin` → "평균 시간" 240초 이하 (Sonnet 기준)

- [ ] **5. 품질 점수 80+ 일관성**
      각 시나리오 결과의 "품질 검증" 탭에서 종합 점수 80 이상

- [ ] **6. SME 평가 평균 4.0/5.0 이상**
      `/admin` → "SME 평균" ≥ 4.0 (최소 평가 3건 이상)

- [ ] **7. 모바일에서도 시연 가능**
      iOS Safari·Android Chrome으로 `/demo` 접근 → 레이아웃 정상

- [ ] **8. 비용 가드레일 작동 확인**
      일일 $50 한도 도달 시 429 응답 + 사용자 메시지 노출 (`DAILY_USD_LIMIT`)

- [ ] **9. 라이브 URL HTTPS 정상**
      `curl -I https://ai-studio-drab-nine.vercel.app` → 200 OK + HSTS 헤더

- [ ] **10. Vercel·Supabase·Anthropic 모두 안정**
       대시보드에서 최근 24시간 이내 에러율 5% 이하

       각 경로 접속 → 빈 페이지·에러 없음

       `git tag -l v0.13.0` → 1개 출력
