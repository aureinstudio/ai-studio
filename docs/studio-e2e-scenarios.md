# Studio E2E 시나리오 (수동 검증)

> **목적:** Studio 13-에이전트 시스템이 다양한 도메인에서 정상 작동하는지 본부장이 직접 확인
> **방법:** `/studio` 페이지에서 각 시나리오를 입력 → 결과 검증
> **자동화:** Playwright 또는 fetch 기반 스크립트는 *미구현* (다음 단계)

---

## 검증 기준 (각 시나리오 공통)

| 항목 | 통과 조건 |
|---|---|
| Status | `completed` (failed·timeout 아님) |
| 응답 시간 | 5분 이내 (Sonnet 기준) |
| 비용 | $1.00 이하 |
| 품질 점수 4개 (#10~#12) | 모두 70+ |
| 결과 JSON 스키마 | 모든 필수 필드 존재 (planning · curator · planner · quality) |
| 활성 에이전트 수 | 11~13개 (스킵 0~2개) |

---

## 시나리오 1: 조리기능사 자격증 - 한식 기초 양념

**입력:**
```
주제: 조리기능사 자격증 - 한식 기초 양념
수준: 초급
길이: 짧음
```

**예상 결과:**
- 활성 에이전트: 13개 (자격증이라 #05·#08 모두 활성)
- 챕터 수: 3~4개
- 슬라이드: 6~10장
- 핵심 키워드 포함: 간장·된장·고추장·소금·설탕
- 품질 점수: 85+

## 자동화 (다음 단계)

다음 단계에서 다음 도구로 자동화:

```typescript
// scripts/e2e-test.ts
const SCENARIOS = [
  { topic: "조리기능사 자격증 - 한식 기초 양념", level: "beginner", length: "short" },
  // ... 4 more
];

for (const scenario of SCENARIOS) {
  const job = await fetch("/api/studio/generate", { method: "POST", body: JSON.stringify(scenario) });
  // poll until completed
  // assert quality scores >= 70
  // log results
}
```

GitHub Actions 통합 시 `npm run test:e2e` 명령으로 실행되도록 구성.
