## 백업 답변 (예상 질문)

| Q | A |
|---|---|
| 환각이 발생하면? | 모든 응답이 #08 환각 검증을 통과. rejected는 학생에 노출 안 됨. /admin/students에 알림. |
| 비용 폭증? | 일일 한도 (Studio $50, Cast $30, Tutor $20) 자동 차단. 한도 도달 시 사용자에게 429 응답. |

| 영상 품질? | HeyGen API 사용. avatar는 KEG가 검증한 동양인 모델 고정. |
| 학생이 부정행위? | #09 안전 감지 자동. content_concern·high 알림 → 강사 즉시 통보. |
| 다음 단계? | Series 5 — 프로덕션 전환 (Slack 알림·Cron 배치·SME 검토 결과 반영). |
