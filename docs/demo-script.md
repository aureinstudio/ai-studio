## 시나리오 흐름 (3분 = 180초)

### [00:00 ~ 00:30] 인트로 (30초)

**대사:**
> "안녕하세요. ai-studio가 만든 첫 베타입니다. KEG가 자체 개발한 AI 교육 플랫폼이죠. 13개 AI 에이전트가 협업하여 교재·강의·평가를 동시에 만드는 구조 — 그 첫 두 단계를 시연하겠습니다."

**화면 흐름:**
1. 라이브 URL 접속 → 메인 랜딩 페이지
2. 다크 네이비 + 모노톤 디자인 노출 (Linear·Vercel 톤)
3. **3개 솔루션 카드**(Studio · Cast · Tutor) 마우스 hover로 떠오름 효과 보여주기
4. 통계 섹션 — "교재 제작 -90% / 강사 의존 -40% / BEP 8개월" 빠르게 paining
5. 헤더 우상단 본부장 이메일 표시 → 이미 로그인 상태 (관객은 모름)
6. **"시작하기"** 버튼 클릭 → `/login` 거치지 않고 곧바로 `/studio`로 (이미 로그인)

> *주의: 시연 *전*에 반드시 로그인 완료 — 미로그인 상태면 /login 거쳐야 함 (UX 흐름 끊김)*

---

### [00:30 ~ 01:00] 입력 (30초)

**대사:**
> "예시로 *조리기능사 자격증* 단원 1개를 만들어보겠습니다. 5초만에 입력합니다."

**화면 흐름:**
1. `/studio` 페이지 진입 — Multi-Agent Chain 헤더 + 폼 보임
2. 주제 입력: **`조리기능사 자격증 - 한식 기초 양념`**
3. 수준 — **초급** 클릭
4. 길이 — 짧음 (이미 선택)
5. **"생성하기"** 클릭

> *대안 시드(검증 완료된 것):*
> - `컴퓨터활용능력 - 엑셀 함수 기본`
> - `토익 - 시제 일치 문법`
> - `정보처리기사 - 데이터베이스 정규화`

---

### [01:00 ~ 02:30] 에이전트 협업 시연 (90초)

**대사 (작업 시작 시):**
> "두 에이전트가 협업합니다. 먼저 핵심 자료 큐레이터가 본문을 쓰고, 그 결과를 받아서 시각 디자인 기획 에이전트가 슬라이드로 재구조화합니다."

**화면 흐름:**
1. 즉시 (1초 내): "Pipeline" 영역 표시 + `✓ 작업 접수됨` 뱃지
2. **#studio-06 핵심 자료 큐레이터** 동그라미 펄스 애니메이션 + `⏳ 실행 중`
3. 약 30-60초 후: 큐레이터 ✓ 체크 + duration·token·cost 표시
4. **#studio-07 시각 디자인 기획** 펄스 시작
5. 약 30-60초 후: ✅ 완료 뱃지 + 결과 3탭 노출

**대사 (대기 중 — 60-90초):**
> "지금 OpenAI나 Google 같은 모델이 아니라 *Anthropic Claude* 모델로 호출되고 있습니다. 1회 호출당 비용은 평균 7-10센트 정도, 한 사람이 하루 5-7회 작업하면 월 $30 정도입니다 — 강사 1명 외주비의 약 5%입니다."
> 
> "그동안 카드 이쪽 구석에 *실제 사용 토큰 수*와 *호출 비용*이 실시간으로 찍힙니다. 가짜 데모가 아니라는 증거죠."

**완료 후 — 탭별 노출 (각 ~15초):**

#### 본문 탭 (15초)
- 챕터 제목·학습 목표 3개·핵심 개념 섹션·실습 예제 카드 *순차 스크롤*
- 강조 포인트: *"한국어 그대로 출력. 번역 아닙니다."*

#### 슬라이드 탭 (15초)
- 6-10장 슬라이드 카드 형태로 표시
- 각 카드: 제목 + 글머리 + Visual 제안 + Speaker Notes
- 강조 포인트: *"강사가 곧바로 강의할 수 있는 형태로 변환됨"*

#### 에이전트 로그 탭 (15초)
- 타임라인 형태 — `studio-06` → `studio-07` 흐름
- 각 에이전트의 시작·종료·duration·token·cost
- 강조 포인트: *"두 에이전트가 *진짜로* 협업했다는 증거. 시간·비용 모두 추적됩니다."*

### [02:30 ~ 03:00] 마무리 (30초)

**대사:**
> "이게 베타 4주차 시점입니다. 8주차에 13개 에이전트로 확장되고, 12주차에 KEG 학생 50명 베타가 시작됩니다. 지금까지 누적 비용은 *$X.XX*. 자세한 로드맵은 사업기획안에 있습니다."

**화면 흐름:**
1. 헤더 **대시보드** 클릭
2. 통계 3카드 노출 — 총 작업 / 이번 달 비용 / 성공률
3. 일일 한도 progress bar 노출 — `$X.XXXX / $50.00`
4. 최근 작업 목록 노출
5. **내 작업** 클릭 → 검색·삭제·공유 액션 잠깐 노출
6. 로고 클릭으로 메인 복귀 + 마무리 인사

## 청중 질문 대비 답변 카드

| 질문 | 답변 키 포인트 |
|---|---|
| "다른 AI 회사 솔루션 쓰면 안 되나요?" | KEG 도메인(자격증 13종) 특화 + 강사 검수 워크플로우 + 사용자 데이터(오답·필기) 자체 보유 |
| "비용은 얼마나 드나요?" | 1회 콘텐츠당 ~$0.10. 학생당 월 ~$5 추산. KEG 인강 객단가 25만원 대비 0.05% (운영 마진 무관) |
| "강사 일자리는?" | 강사 *대체*가 아닌 *증폭*. 콘텐츠 제작 부담 -90% 후 강사는 *학생 1:1 코칭에 집중*. 총 매출/강사 ↑ 가능 |
| "보안은?" | Supabase RLS + Vercel Sensitive env + Anthropic Zero retention. 학생 데이터는 KEG 자체 DB |
| "언제 학생들이 쓸 수 있나요?" | 베타 50명 PoC 8월 종료 → 합격 시 9월부터 단계 확대. NO-GO 시 전략 재검토 |
| "환각(hallucination) 문제는?" | 11번 에이전트 *환각 검증*이 8주차 추가. 자동 차단 + 강사 검수 게이트 이중 |
